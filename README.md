# 🚚 Smart Optimizing Delivery ETA Intelligence System

AI-Powered Logistics Optimization & ETA Intelligence Platform

## Features
- Real-time delivery ETA prediction using ML models
- Live network graph with bottleneck detection
- 3 rider live tracking on map
- ETA alerts system
- PDF report export
- Flask API integration

## How to Run

### Install dependencies
pip install -r requirements.txt

### Run the dashboard
streamlit run dashboard.py

### Run the Flask API (optional)
python app.py
